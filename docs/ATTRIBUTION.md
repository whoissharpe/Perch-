# Attribution

Perch shows third-party data and photographs. Both carry licence conditions,
and both are conditions rather than courtesies.

## Base map and nearby spots

Map data (c) OpenStreetMap contributors, licensed ODbL. Two things use it: the
base map tiles, and `apps/mobile/src/nearby.ts`, which queries the Overpass API
live for real benches and viewpoints around the user. The in-app attribution
control is a licence condition and must stay legible.

## Perch Picks photographs

The picks in `apps/mobile/src/curated.ts` are real, verifiable places. Every
photograph below has been opened and checked by eye: a bench, or built-in
seating, is visible in the frame. Coordinates come from OpenStreetMap,
cross-checked against each place's encyclopedia record. Credit renders over the
photo on the card and again on the spot detail screen, next to a source link.

## Dropped for having no bench in any free photograph

Fort Caroline, Kingsley Plantation, the Ribault Club, Fort Clinch, the
Jacksonville Beach pier, the Cummer gardens, Buckden Pike, Cadair Idris, the
Singing Ringing Tree, Stegastein and Gaularfjellet. All real places; none has a
freely licensed photograph showing anywhere to sit. Big Talbot Island was
dropped earlier for the same class of reason -- its only free image is of the
park entrance sign. If someone photographs a bench at any of them and releases
it freely, they go back in.

If a licence here is ever found to be misstated, treat it as a bug and fix it
before the next release rather than after.
