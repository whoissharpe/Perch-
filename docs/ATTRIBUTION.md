# Attribution

Perch shows third-party data and photographs. Both carry licence conditions,
and both are conditions rather than courtesies.

## Base map and nearby spots

Map data (c) OpenStreetMap contributors, licensed ODbL. Two things use it: the
base map tiles, and `apps/mobile/src/nearby.ts`, which queries the Overpass API
live for real benches, viewpoints, shelters and picnic tables around the user.
The in-app attribution control is a licence condition and must stay legible.

## Perch Picks photographs

The picks in `apps/mobile/src/curated.ts` are real, verifiable places, chosen to
be unfamiliar rather than famous. Coordinates were taken from OpenStreetMap and
cross-checked against each place's encyclopedia record; photographs are freely
licensed images from Wikimedia Commons. Credit renders over the photo on the
card and again on the spot detail screen, next to a link back to the source.
